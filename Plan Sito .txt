## Strade possibili (con tradeoff)
### A) **Serverless "tutto-in-uno"** — *raccomandato per time-to-market*
Stack: **Cloudflare Pages** (hosting statico + CDN + TLS automatico) + **Cloudflare Workers** (funzione `/api/contact`) + **Cloudflare Turnstile** (anti-bot gratuito) + **Resend** o **Postmark** (SMTP transazionale) + **Cloudflare D1** o **Supabase** (DB submissions).
- **Pro:** zero gestione server, free tier ampio (Cloudflare è praticamente gratuito per questo traffico), deploy automatico da GitHub push, TLS automatico, DDoS protection, edge CDN globale.
- **Contro:** vendor lock-in moderato (Workers API); Resend ha sede USA (valutare data residency GDPR, ma adeguata).
- **Costo stimato:** 0–5 €/mese fino a migliaia di richieste/mese.
### B) **VPS tradizionale** — *controllo massimo*
Stack: **Hetzner CX11** (Finlandia/Germania, 4 €/mese) + **nginx** + **Node.js/Fastify** o **Python/FastAPI** + **PostgreSQL** locale + **Postfix** o SMTP esterno + **Certbot** per TLS.
- **Pro:** controllo completo, dati in UE, nessun lock-in, stack portabile.
- **Contro:** devi gestire tu updates OS, backup, hardening SSH/firewall, rinnovi TLS, monitoraggio. Per un form è sovra-dimensionato.
- **Costo:** ~5 €/mese fisso + tempo ops.
### C) **Ibrido Netlify/Vercel + Supabase** — *DX moderno*
**Netlify** (hosting + Functions + form built-in che salva in dashboard + webhook) o **Vercel** + **Supabase** (Postgres gestito in UE).
- **Pro:** Netlify Forms gestisce submission/spam/email notification out-of-the-box (zero codice backend per il form base). Supabase offre DB + auth se un domani serve area riservata.
- **Contro:** Netlify free tier ha 100 submissions/mese (poi a pagamento). Vercel Functions hanno cold start.
- **Costo:** 0 € fino ai limiti, poi 19 $/mese (Netlify Pro).
### D) **Form-as-a-service puro** — *MVP in 1 ora*
**Cloudflare Pages** (statico) + **Formspree** / **Web3Forms** / **Basin** come endpoint form.
- **Pro:** set up in 10 minuti, niente da scrivere lato backend.
- **Contro:** dati su servizio terzo (GDPR DPA da firmare), personalizzazione limitata, no CRM integrato.
- **Costo:** 0–10 €/mese.

## Fase 1 — Infrastruttura dominio & DNS (senza codice)
1. **Account Cloudflare** — creo account gratuito (email dedicata, consigliata `admin@faktotum.it` una volta attiva, altrimenti personale).
2. **Aggiungere `faktotum.it` su Cloudflare**
   - Piano Free
   - Cloudflare esegue scansione record DNS esistenti (da Register.it) e li importa
   - Cloudflare fornisce 2 nameserver (es. `xxx.ns.cloudflare.com`)
3. **Register.it → cambio nameserver**
   - Login pannello Register.it → Dominio → Nameserver → inserire i 2 NS Cloudflare
   - Propagazione: 15 min – 24 h
4. **Verifica attivazione** — status "Active" in dashboard Cloudflare
5. **Record DNS da configurare su Cloudflare:**
   - `A` / `AAAA` / `CNAME` per `faktotum.it` e `www.faktotum.it` → creati automaticamente da Cloudflare Pages (step 2)
   - `MX` → mantieni i record mail di Register.it (copiati automaticamente) per `admin@faktotum.it`
   - `TXT SPF`, `DKIM`, `DMARC` → aggiunti in Fase 3 per deliverability Resend
6. **TLS** — Cloudflare emette automaticamente certificato universale "Full (strict)"

Responsabilità di functions/api/contact.ts
1. Metodo: accetta solo POST, rifiuta altri con 405
2. Parse application/x-www-form-urlencoded o multipart/form-data
3. Validation server-side:
   - name 2–100 char
   - email regex RFC
   - profile ∈ ['privato', 'business']
   - privacy === 'on'
   - Campi testo opzionali: clamp lunghezza (coerente con maxlength HTML)
4. Verifica Turnstile:
   - POST a https://challenges.cloudflare.com/turnstile/v0/siteverify con secret + token dal form
   - Se fail → 403
5. Honeypot — campo nascosto <input name="website" style="display:none"> che se compilato = bot → 204 silenzioso
6. Rate limit:
   - Cloudflare Worker + KV per contatore IP → max 3 richieste/10 min per IP
   - Oppure delegato a Cloudflare WAF Rate Limiting rule
7. Invio email via Resend:
   - Email #1 → admin@faktotum.it con tutti i campi formattati (HTML + testo)
   - Email #2 → email utente con conferma ricezione (template cordiale, link privacy)
8. Risposta: JSON { success: true } su 200, { error: "..." } su 4xx/5xx
9. Logging: console.log strutturato → visibile in Cloudflare dashboard
10. Segreti (wrangler secret / Pages env vars):
    - RESEND_API_KEY
    - TURNSTILE_SECRET_KEY
    - ADMIN_EMAIL=admin@faktotum.it
